# Panel Agent 对话记录（2.6.0-cloudssh.56）

## 保存与恢复

Panel Agent 的正式聊天记录改为 CloudSSH 应用数据库中的
`panel_agent_conversations` 和 `panel_agent_conversation_messages`，随现有数据库
加密配置和数据库备份保存。表结构为增量、幂等创建，不删除旧业务数据。
浏览器仅在 sessionStorage 保存按登录账号隔离的当前对话 ID；不再将完整新聊天写入
localStorage。登录同一账号的其他设备可在“历史管理”中查看记录。

用户消息保存成功后才请求模型；模型回复由后端保存成功后才返回，前端再执行其工具
调用。工具返回的观测结果也保存后才进入下一轮。保存失败会停止新的工具操作，并在
页面保留尚未保存的内容供导出或重试。突然断网、关闭浏览器时尚未确认保存的数据
不保证已落库；重新载入前应先导出页面内未保存内容。

记录包括聊天文本、模型名称、工具调用及返回内容、已上传图片 data URL、文本附件
和其他附件元数据。不额外上传旧版没有读取的二进制文件，也不意味着保存完整 SSH
输出流：工具返回多少观测内容就保存多少。SSH 录像和安全审计仍是独立系统；浏览器
提交的工具结果属于个人对话记录，不是不可篡改的执行审计。

恢复历史仅载入内容，不自动连接服务器、不重放历史命令。原终端失效时应先重新选择
可连接的终端，再发送新要求。未确认结果的历史工具调用会标为不确定，不能当作成功。

## 界面操作

- **历史管理**：搜索标题或聊天内容、筛选当前服务器、分页载入历史。
- **新建对话**：保留原对话并开始新记录。
- **清空 / 删除**：确认后永久删除指定对话的消息、附件和摘要，不删除 SSH 录像。
- **清空当前账号 / 当前服务器历史**：明确确认后按该范围删除；不受搜索关键词限制。
  多服务器对话被任一关联服务器匹配时会整条删除。
- **重命名**：修改标题，不修改消息。
- **导出原文**：在历史列表下载完整 JSON；聊天面板“导出当前内容”下载当前已加载
  消息及未保存内容，较早未加载的消息应通过历史列表完整导出。
- **加载更早的原始消息**：每次载入 100 条；不会用摘要替换原文显示。

导出文件可能含服务器命令、输出和附件，请妥善保存。删除在线记录不能撤回已有的
导出文件、模型提供商日志或备份；这些需要按各自的保留策略处理。

## 摘要压缩

“压缩对话”使用当前配置的模型生成语义摘要，会消耗模型额度。压缩只更新单独的摘要
字段及覆盖边界，原文、消息 ID、图片、工具结果仍保留。最近两轮用户对话不压缩，
更长历史分批处理。摘要可能遗漏细节，不能替代原文或实时终端检查。

默认启用自动摘要：未摘要内容超过 80 条消息或约 180,000 个序列化字符时，下一次
模型请求尝试压缩较早的完整对话轮次。每次摘要输入和输出均有大小限制。生成失败
保留旧摘要及原文，模型请求仍只使用有上限的最近上下文，并向界面返回提示。

摘要和裁剪内容以历史资料传给模型，不提升为系统指令。加载记录、删除、导出、生成
摘要都不会执行 SSH 命令。不要把这些字符阈值当作模型 token 上限；模型能力和图片
输入还有各自的限制。

## 权限、并发和容量

每个对话属于一个登录用户。读取、搜索、导出、续聊、摘要都校验所有关联服务器的
当前连接权限；管理员不会因此自动获得他人的私人聊天。权限在耗时模型调用结束后
再次检查。用户仍可删除自己已失去服务器访问权的记录。账号删除会清理所属对话。

追加使用稳定消息 ID 幂等去重和 revision 乐观并发控制。另一设备更新后，过期写入
返回 409，而不是覆盖历史。请先导出本地未保存内容，再重新载入服务器版本。模型
请求有稳定请求 ID 和同对话互斥；已保存回复的网络重试不会自动重放工具命令。
从早期用户消息重试会创建独立分支对话，保留原对话的后续消息。

默认容量为每条对话 64 MiB、每个账号合计 256 MiB、每条对话 20,000 条消息、每个
账号 1,000 个对话。可由部署管理员设置：

```text
PANEL_AGENT_CONVERSATION_MAX_BYTES=67108864
PANEL_AGENT_USER_HISTORY_MAX_BYTES=268435456
```

达到上限会拒绝新的保存并提示导出/清理，绝不为腾空间悄悄删除原文。摘要压缩不减少
完整归档容量。这些记录随现有内存数据库快照落盘，容量配置应考虑服务器内存、备份
体积和磁盘空间。

## 旧浏览器记录迁移

“历史管理”会检测旧的 `panelAgentLiveConversation` 和
`panelAgentConversationHistory`。旧数据没有可靠账号标识，因此**不会自动上传**：
用户必须确认这些记录属于当前登录账号后导入。导入按账号及内容幂等去重，失败可以
重试；全部导入成功后才提供清理旧缓存按钮。

旧版已裁剪或未成功保存的内容无法凭空恢复。旧记录默认不绑定服务器，后续在对应
终端继续聊天时才添加经过权限检查的服务器关联。
